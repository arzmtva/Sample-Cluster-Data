# Smart Cluster Data

## Описание проекта

Данный проект представляет собой ML-систему кластеризации данных с использованием алгоритма K-Means.

Система анализирует входные данные, автоматически распределяет объекты по группам (кластерам) и помогает находить скрытые закономерности в данных без использования готовых меток.

Проект включает обучение модели, обработку данных, визуализацию кластеров и веб-интерфейс для взаимодействия с моделью.

## Цель проекта

Цель проекта — продемонстрировать работу unsupervised learning (обучения без учителя) на наборе данных Sample Cluster Data, где модель обучается:

- находить похожие объекты
- автоматически разделять данные на группы
- анализировать закономерности
- визуализировать распределение кластеров
- работать с новыми пользовательскими данными
- предсказывать принадлежность к кластеру

## Установка и запуск

### 1. Клонировать репозиторий

git clone https://github.com/arzmtva/Sample-Cluster-Data.git

cd Sample-Cluster-Data

### 2. Создать виртуальное окружение

Windows:

python -m venv venv

venv\Scripts\activate

Linux / MacOS:

python3 -m venv venv

source venv/bin/activate

### 3. Установить зависимости

pip install -r requirements.txt

### 4. Обучить модель

python train.py

После выполнения будут созданы файлы:

- model.pkl
- scaler.pkl
- feature_names.pkl
- final_dataset.csv

## Запуск веб-приложения

python app.py

## Открыть в браузере

http://127.0.0.1:5000

## Как работает модель

В проекте используется:

- K-Means Clustering для разделения данных
- StandardScaler для нормализации признаков
- машинное обучение без учителя (Unsupervised Learning)
- автоматическое определение похожих объектов
- сохранение модели через Pickle

Модель выполняет:

- анализ входных данных
- масштабирование признаков
- распределение объектов по кластерам
- прогнозирование принадлежности к группе
